## 正在构建：MatrixOne Intelligence

MatrixOne Intelligence（MOI）是一套面向企业复杂数据与知识工作的 AI 产品路径：将多模态数据接入、处理治理和 AI-Ready Data，与知识库、工作流、Agent 应用、API 集成及平台治理连接起来。

我重点关注：

- **数据到 AI 的路径：**多模态数据接入、加工处理、数据治理与可用于 AI 的数据资产。
- **知识与任务执行：**复杂文档理解、知识检索、工作流编排、Agent 应用与工具集成。
- **企业级治理：**权限、数据边界、可追溯性、可观测性、模型服务治理与持续优化。
- **产品验证：**以真实业务场景组织 POC、Storybook、端到端验收与质量评测。

[查看 MOI 产品案例集](https://github.com/vitoworleone/matrixone-intelligence-casebook) · [体验 MOI 平台原型](https://moi-platform-prototype.vercel.app) · [查看 Astra](https://github.com/vitoworleone/Astra)

## 代表性工作

### 金融工作流与证据链治理

参与 ABS 与公司债项目，覆盖底层资产资料治理、财务分析、信用尽调、立项申报、反馈回复与封卷归档等环节；关注如何将多主体、多版本、跨文件材料组织为可审核、可追溯的业务证据链。

### 金融智能体评测

围绕真实金融业务设计 Agent Benchmark 与程序化 Verifier，覆盖 ABS 底稿建档、财务报表提取与勾稽、银行流水及凭证处理等任务；用规则校验与受约束模型判断结合的方式，评估 Agent 是否真正完成工作，而不只看最终文件是否生成。
