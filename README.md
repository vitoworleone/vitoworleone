## 🌐 社区与研究

### Organization World — 组织级 Agent 协作评测

WebAgentLab 社区项目，与上海人工智能实验室合作推进。

多数评测关心的是：单个 Agent 能否完成一道独立任务。Organization World 更关心：多角色在真实任务依赖下协作，且不在每个交接环节提供干净中间答案时，智能体团队是否仍能稳定完成端到端交付。

我关注的方向：

- 组织级评测的问题定义
- 协作链路上的误差传播与交接损耗
- 阶段任务、验证方式与 case 设计
- 从群聊、文档、里程碑等真实协作产物提炼可评测样本
- 对标公开 benchmark，收敛评测设定与落地路径

## 🧭 我的产品观

> **AI Native 不是在旧产品上增加一个聊天框，而是重新设计数据如何流动、任务如何执行、结果如何被信任。**

我相信优秀的 AI 产品经理需要同时理解用户任务、模型行为与系统边界：既能定义产品价值，也能深入上下文工程、Agent 编排、评估体系和生产可靠性，把模型能力真正转化为稳定的产品能力。
