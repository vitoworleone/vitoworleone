## Building: MatrixOne Intelligence

MatrixOne Intelligence (MOI) is an enterprise AI product path that connects multimodal data ingestion, processing, governance, and AI-ready data with knowledge bases, workflows, agent applications, API integration, and platform governance.

I focus on:

- **Data-to-AI foundations:** multimodal ingestion, data processing, governance, and AI-ready data assets.
- **Knowledge and task execution:** complex-document understanding, knowledge retrieval, workflow orchestration, agent applications, and tool integration.
- **Enterprise governance:** permissions, data boundaries, traceability, observability, model-service governance, and continuous improvement.
- **Product validation:** real-world POCs, Storybook scenarios, end-to-end acceptance, and quality evaluation.

## Selected Work

### Financial Workflows and Evidence Systems

Worked on ABS and corporate-bond workflows spanning underlying-asset documentation, financial analysis, credit due diligence, filing materials, regulatory-feedback responses, and closing archives. I focus on organizing fragmented, multi-version materials into reviewable and traceable evidence chains.

### Financial Agent Evaluation

Designed financial-domain agent benchmarks and programmatic verifiers for ABS documentation, financial-statement extraction and reconciliation, and bank-statement and voucher processing. The aim is to assess whether an agent actually completes work—not merely whether it generates a plausible file.
