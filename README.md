## 我关注的工作

### 金融 Agent 任务与评测

我关注的不是 Agent 能否生成一份“看起来完整”的文件，而是它能否完成被审阅、被追溯的业务任务。

在金融 CUA Benchmark 中，一个任务包含：Agent 指令、业务上下文、初始状态、正确目标状态和 Verifier。评分不仅比较最终数字，也检查主体、期间、单位、公式、来源映射、正式提交状态和任务安全边界。

[查看任务设计方法](https://github.com/vitoworleone/financial-cua-benchmark/blob/main/docs/01-benchmark-positioning.md) · [查看 Verifier 架构](https://github.com/vitoworleone/financial-cua-benchmark/blob/main/docs/03-verifier-architecture.md) · [查看校验项说明](https://github.com/vitoworleone/financial-cua-benchmark/blob/main/docs/04-checker-guide.md)

### 企业 AI 数据与智能体系统

复杂业务中的 Agent 需要可靠的数据、明确的权限、可调用的工具和可观测的运行过程。我围绕以下问题设计产品：

- 多模态数据接入、加工、治理与 AI-Ready Data；
- 复杂文档理解、知识检索、工作流编排和 Agent 应用；
- 权限、数据边界、审计追溯、可观测性和持续评测；
- 通过 POC、端到端验收和真实业务反馈推动产品迭代。

### 金融工作流与证据链

我参与过 ABS 与公司债相关工作，关注底层资产资料、财务分析、信用尽调、申报材料、反馈回复与封卷归档。核心挑战是将多主体、多版本、跨文件材料组织成可审核、可追溯的证据链，并让人和 Agent 可以在同一套工作流中协作。
